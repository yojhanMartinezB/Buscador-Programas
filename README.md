# Buscador-Programas
Buscador de Programas Académicos por Prefijos

Descripción:

Este proyecto consiste en desarrollar un buscador de programas académicos utilizando Python. El sistema permite consultar un catálogo de programas mediante la búsqueda por prefijos, mostrando aquellos nombres que comienzan con el texto ingresado por el usuario.

¿Entonces cual seria el objetivo?=
En si seria la aplicación de conceptos de estructuras de datos, yendo específicamente a las cadenas de caracteres(str),diccionarios(dict) y algoritmos de busqueda por preijos.


Tecnologías

-Lenguaje: Python 3.

-Estructuras de datos: diccionarios, listas y tuplas.

-Tipo de dato: cadenas de caracteres (str).

-Métodos utilizados: items(), lower(), strip() y startswith().

-Librerías externas: no se requieren librerías adicionales.
